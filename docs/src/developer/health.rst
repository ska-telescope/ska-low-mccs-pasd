======
Health
======

PaSD uses the `HealthRecorder <https://developer.skao.int/projects/ska-low-mccs-common/en/latest/reference_material/health_recorder.html>`_
class to implement a health model for each device (FNDH, FNCC, PasdBus and Smartbox).

This is then aggregated into an overall health for FieldStation; see :ref:`fieldstation-health-evaluation` for details.
